# Benday

Benday is an Android reader for [Komga](https://komga.org),
[Kavita](https://www.kavitareader.com), [Stump](https://www.stumpapp.dev),
[Suwayomi](https://github.com/Suwayomi/Suwayomi-Server),
[BookOrbit](https://github.com/bookorbit/bookorbit) and OPDS catalogs: comics, manga and webtoons from your own server, online or
offline.

**Website: <https://getbenday.com/>**

This repository holds the website and is where feedback goes. The app's
source code is not public.

## Feedback

[Open an issue](https://github.com/PalleKarlsson/benday/issues/new) for a
bug, an idea or a question, or use the
[feedback form](https://getbenday.com/feedback.html),
which fills one in for you. Search the
[existing issues](https://github.com/PalleKarlsson/benday/issues) first; a
👍 on an idea counts as a vote.

Issues are public: leave out your server's address, usernames and
passwords.

For a bug, include the Benday version (Settings › About), your Android
version and device, your server and its version, and the steps that lead to it.

Benday is not affiliated with Komga, Kavita or the other servers it reads
from.
